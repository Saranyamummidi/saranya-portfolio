# Saranya Mummidi — Developer Portfolio

A responsive, single-page dark developer portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and dynamic footer year
- `resume.pdf` — résumé linked from the hero section

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required. Google Fonts are loaded online; the page still works with fallback fonts if offline.

## Customize
- Update text, skills, project descriptions and links in `index.html`.
- Change colors in the `:root` variables at the top of `style.css`.
- Replace `resume.pdf` with an updated résumé using the same filename.
- Add GitHub or live-demo links to each project when you have public repositories or deployed demos.

## Publish free
You can publish this folder using GitHub Pages:
1. Create a GitHub repository and upload these files.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/root`, then save.
4. GitHub will provide your public portfolio URL.

Check your phone number, email, résumé, and LinkedIn URL before publishing publicly.
